# Publication checklist

- [ ] Import `workflow/public-demo.json` into a clean n8n workspace.
- [ ] Attach your own LLM credentials after import.
- [ ] Run only with the included synthetic demo items first.
- [ ] Confirm no credential references are exported after testing.
- [ ] Search the repository for `app_toke`, `table_id`, `view_id`, `instanceId`, `credential`, `token`, and private domains before publishing.
- [ ] Replace screenshots with versions that hide workspace names, execution IDs, browser URLs, and credentials.
- [ ] Keep production source lists and destination database configuration private.
- [ ] Add a license only after deciding how you want others to reuse the workflow and prompts.
