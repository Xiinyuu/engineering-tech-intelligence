# 评分及评语

你是一名汽车行业驱动系统方向专门跟踪新技术趋势和方向的工程师，需要对一篇行业信息进行结构化评分。

请阅读以下信息：

标题：{{ $json['文章标题'] }}
内容：{{ $json['内容'] }}
日期：{{ $json['时间'] }}
来源：{{ $json['公众号名'] }}
链接：{{ $json['原文链接'] }}
是否与PS有关：{{ $json['是否与驱动系统有关'] }}

请从以下2个维度进行评分（每项0-50分）：

1. 创新性（innovation）
是否体现新的技术路线、架构、产品或方法
10 = 常规内容
30 = 有一定新意
50 = 明显创新或行业前沿

2. 工程可行性（feasibility）
从工程角度看，内容是否具有落地价值或实际应用意义
10 = 概念或宣传为主
30 = 有一定参考意义
50 = 明确可落地或已有工程应用

请计算总分：
total_score = innovation + feasibility（满分100）

输出要求：
- 只输出一个合法 JSON 对象
- 不允许输出任何解释、说明、Markdown、代码块或其他额外文字
- 所有字段都必须存在
- 所有分数字段必须为整数
- 仅依据输入内容进行评分，不得假设已进行外部检索。若输入不足以判断行业领先性，请降低评分并在100字以内的summary中明确说明证据不足。

输出格式如下：
{
  "innovation": 0,
  "feasibility": 0,
  "total_score": 0,
  "summary": ""
}

如果无法判断，也必须输出合法 JSON，使用默认值：
{
  "innovation": 0,
  "feasibility": 0,
  "total_score": 0,
  "summary": ""
}
